Side-by-Side Architectural Comparison

Previous: Additive Noise Field Isolated Island Spots

Formula: t(x, y) = base_sweep(x, y) + noise(x, y)

Directly adding noise to scalar values creates local extrema away from the gradient slope. This causes isolated island blobs (notice the floating cyan islands and disconnected dark spots in the center).

New: Domain Warping (Nested Vectors) Seamless Fluid Currents

Formula: u' = u + A·q_x(u, v), v' = v + A·q_y(u, v)

Coordinate space is deformed as an incompressible vector field. Colors flow organically along continuous river currents without any blotchy spot artifacts.

Warp Strength Sweep (0.0 → 1.6)

Demonstrates how varying --warp-strength controls the fluid geometry from a clean linear transition to swirling marble currents.

Mathematical Formulation

// Primary directional sweep coordinates
u = x * cos(θ) + y * sin(θ)
v = -x * sin(θ) + y * cos(θ)

// Level 1: Primary displacement vectors
q_x = noise2d(u * freq + Ω1, v * freq + Ω2)
q_y = noise2d(u * freq + Ω3, v * freq + Ω4)

// Level 2: Nested coordinate displacement
u' = u + warp_strength * q_x
v' = v + warp_strength * q_y
r_x = noise2d(u' * 1.3 * freq + Ω5, v' * 1.3 * freq + Ω6)

// Final continuous scalar field
t(x, y) = normalize(u' + 0.4 * warp_strength * r_x) ∈ [0, 1]
color(x, y) = PchipInterpolator(nodes, colors_oklab)(t(x, y))
